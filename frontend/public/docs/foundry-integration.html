ADR 0010: Use a hosted agent that cannot recalculate Strategy metrics

  • Status: accepted
  • Date: 2026-11-19
  • Context: Housing staff need a plain-language explanation of the governed

Strategy snapshot, missing details, and linked HPD guidance. The agent must not invent metrics or make enforcement decisions.

  • Decision: Use a Microsoft Foundry hosted agent with the Responses protocol.

Strategy Mosaic remains the source of metric definitions and values. The agent receives only safe evidence and approved citations.

  • Consequences:

- The same Strategy metric meaning appears in the dashboard, app, and briefing. - The agent code is configuration-driven and can be deployed from azure.yaml. - Local and CI tests use the deterministic Practice provider instead of a paid model. - A staff member must verify every suggested follow-up before taking action. - Live use is deployed with separate consumer and model-inference identities.

Callback allowlist

The Foundry connection created for this project uses:

https://global.consent.azure-apim.net/redirect/7562f5510708426eacbf4e931db046ad

A Strategy administrator should allow that exact URL, or the supported wildcard:

https://global.consent.azure-apim.net/redirect/*

They add it in Strategy Workstation under Environment Properties > Library > Model Context Protocol for Agent > Callback URL, save, and restart the Library/Collaboration service if required.

global.consent.azure-apim.net is Microsoft's OAuth consent broker. It receives the authorization code from Strategy and passes the resulting connection token to Foundry. It does not store or query HPD data.

Foundry connection status

The strategy-mosaic-mcp connection and strategy-tools toolbox are created. OAuth consent is complete. Authenticated tools/list, get_projects, and get_models calls succeed.

The signed-in Strategy user can currently access:

  • project: Strategy Showcase;
  • model: Retail Orders Sales Performance Model (global).

The MCP server does not currently expose the Heat and Hot Water Review Model to this user. A Strategy content owner or administrator must:

  1. publish that Mosaic model in the Strategy Showcase project, or move an

equivalent model there;

  1. certify it for MCP access; and
  2. grant the consented Strategy user view access to it.

Foundry briefing

The hpd-review-agent is a code-deployed hosted agent. It uses the Responses protocol and the configured gpt-5.4-mini deployment.

Strategy Mosaic remains the source of metric definitions. The agent cannot recalculate a Strategy metric. It can explain the supplied evidence, unknowns, suggested follow-up, and linked HPD guidance.

The deployed demo calls hpd-review-agent through FOUNDRY_AGENT_ENDPOINT. Local tests use the deterministic Practice provider. That fallback is visible in the user interface and never pretends to be a live model response.

The agent is deployed as an active hosted agent version and the public app is authorized with the Foundry Agent Consumer role. The agent identity has the separate Cognitive Services OpenAI User role needed to call the model.

ADLS controls

  • Hierarchical namespace is enabled.
  • Anonymous blob access is disabled.
  • Shared storage key access is disabled.
  • The app and developer receive Storage Blob Data Contributor only where they

need to write.

  • External Strategy connector credentials are configured outside the repository.
