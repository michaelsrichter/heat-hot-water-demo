Cost

The demo separates fixed platform cost from use-based AI and data cost.

  • cost-to-run.md describes the services used today and the

likely bill drivers.

  • cost-at-scale.md explains what to measure at 10x and

100x usage.

The Bicep budget starts at USD 50 per month. It alerts at 80% of actual spend and 100% of forecasted spend. A budget alert does not stop resources or guarantee a hard ceiling.

The hosted app can scale to zero when idle. Practice mode makes no paid model call. The live briefing path creates model usage, so public access remains bounded by saved scenarios and rate limits.

Canonical source: cost/cost-to-run.md

Cost to run

Azure has created the resource group, ADLS account, container, monitoring, registry, and Container Apps environment in the signed-in demo subscription. No measured billing amount is claimed yet.

The new ADLS Gen2 path adds:

  • a standard locally redundant StorageV2 account;
  • a hot-tier data container;
  • storage diagnostic logs; and
  • read and write operations from ingestion and Strategy refresh.

The data size is small for a demo. Log Analytics and Container Apps are more likely cost drivers than Blob capacity.

The template retains a USD 50 monthly budget alert. This is a default ceiling, not an approved spending commitment. Budget alerts do not stop paid workloads.

Power BI/Fabric capacity is not required by this architecture.

Canonical source: cost/cost-at-scale.md

Cost at scale

Storage cost changes with retained dated archives, file format, and refresh frequency. Strategy's scheduled import affects compute in the Strategy environment, not every visitor.

Measure these cases after deployment:

UsageMeasure
Current demoBlob GB, write operations, Strategy refresh duration, Log Analytics GB
10x refreshesBlob operations, Strategy refresh jobs, Container App starts
100x refreshesQuotas, rate limits, archive retention, and global review run cap

Delete archives by retention policy only after evidence retention is approved. Do not increase the archive window merely to preserve every demo run.
